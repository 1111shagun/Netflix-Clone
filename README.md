## ✨ About the Project

This project is a front-end clone inspired by the Netflix India landing page. It recreates the familiar streaming-platform experience using **HTML for structure and CSS for styling and responsiveness**.

The goal is to practise front-end development by building a visually engaging interface with movie posters, membership forms, FAQ accordions, and a cinematic dark theme.

> 🎯 Project Goal: Turn basic HTML and CSS skills into a polished, responsive web interface.

## 🔥 Features

| Feature | Description |
|---|---|
| 🎥 Cinematic Hero | Background image with a dark overlay |
| 🍿 Trending Now | Horizontally scrollable movie poster gallery |
| 🔢 Ranking Numbers | Large numbered overlays on movie cards |
| 💎 Reason Cards | Gradient cards highlighting streaming benefits |
| ❓ Interactive FAQs | Expandable questions using HTML `<details>` and `<summary>` |
| 📧 Email Forms | Email inputs with built-in HTML validation |
| 📱 Responsive Design | Layout adjustments for desktop, tablet, and mobile |
| ✨ Hover Effects | Movie cards scale smoothly on hover |
| 🔗 Footer Navigation | Links for common help and information sections |
